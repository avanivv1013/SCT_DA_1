# Superstore Sales and Profitability Analysis Dashboard

## Project Executive Summary
This project was developed during a Data Analyst Internship at SkillCraft Technology. The objective was to analyze the Global Superstore dataset to identify key performance drivers. By transforming raw transactional data into an interactive dashboard, this tool allows for a detailed examination of sales, profit, and regional trends to support business decision-making.

## Technical Workflow

### 1. Data Organization
* Data Source: Utilized the Global Superstore dataset, including Orders, People, and Returns tables.
* Structure: Organized raw data into a structured format suitable for high-level aggregation and visualization.

### 2. Analysis through Pivot Tables
* Metric Aggregation: Created multiple Pivot Tables to calculate Total Sales and Total Profit.
* Categorical Breakdown: Grouped performance data by Region (West, East, Central, South) and Product Category (Furniture, Office Supplies, Technology).
* Time-Series Analysis: Aggregated sales data by Year and Month to identify seasonal peaks and performance fluctuations between 2015 and 2018.

### 3. Dashboard Visualization
* Dynamic Components: Built a central dashboard using various chart types to represent business metrics visually.
* Interactive Filters: Integrated Slicers and Timelines, allowing users to filter the entire dashboard by specific regions or time periods.
* KPI Identification: Highlighted high-level metrics including Total Sales (over $2.2M) and Total Profit (approximately $286k) for immediate performance assessment.

---

## Strategic Business Insights

* Market Leadership: The West Region is the primary revenue driver, contributing $725,457 to the total sales volume.
* Profitability Comparison: While Technology generates the highest profit ($145k), the Furniture category shows significantly lower margins ($18.4k), suggesting a need for cost review in that sector.
* Seasonal Performance: Sales data reveals consistent peaks in the fourth quarter (September through December) across the analyzed years.
